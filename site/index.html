Reach any EC2 instance in any of your AWS accounts with one command.

hop finds your instances across every AWS profile on your machine, lets you pick one by name, and opens an AWS Systems Manager Session Manager shell. No SSH keys, no bastion, no instance IDs to copy.

Type what you remember

A name, a few words, an instance ID or a private IP. hop searched every profile, each in its own region, checked your SSO token and whether the account logs sessions, then connected.

Everything Session Manager, without the ceremony

One tool for the whole fleet, from your laptop or a container.

Every account, one command

Each profile is queried in its own region, in parallel, and cached. hop scan finds instances in regions you forgot.

SSO that just works

Profiles are grouped by SSO portal: one hop login covers every account behind it. An expired token is caught before connecting.

More than shells

hop run keeps the remote exit code, hop tunnel forwards ports (also to hosts behind the instance), hop push copies small files with a SHA-256 check.

Knows if you are recorded

Before a shell, hop reads the account's Session Manager preferences and shows where the session is logged, or warns you. transcript: require refuses unlogged sessions.

A health check for your AWS setup

hop doctor spots expired tokens, revoked or long-lived keys, profiles defined twice and unlogged accounts, each with the command that fixes it.

Everywhere you work

macOS, Linux and Windows, on amd64 and arm64, with zsh, bash, fish and PowerShell completion.

Safe by default

hop opens shells on real servers, so it never guesses.

Exact or it asks

It acts on its own only on an unambiguous match. An IP or instance ID must match exactly: 10.0.1.2 never picks 10.0.1.21.

Fresh before acting

When its data is more than a minute old, hop looks the chosen instance up again. A stopped, renamed or replaced instance is never acted on.

No terminal, no guess

In scripts, hop lists the candidates and stops. run and push default to no when they ask.

Releases you can verify

Built by GitHub Actions from tagged commits on main, with signatures and provenance anyone can check.

Checksums and container images are signed keylessly with Sigstore cosign.
